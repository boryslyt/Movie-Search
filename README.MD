# 🎬 Movie Search

A simple movie search application built with HTML, CSS, and JavaScript.

The app uses the OMDb API to search for movies and display information about them.

## Features

- 🔍 Search movies by title
- 🎬 Display movie posters, titles, and release years
- 📖 View additional movie information:
  - Genre
  - Runtime
  - Director
  - Actors
  - IMDb rating
  - Plot
- ❤️ Add and remove movies from favorites
- 💾 Favorites are saved using LocalStorage
- ⌨️ Search by pressing Enter
- ⏳ Loading states while fetching data
- ⚠️ Error handling for failed requests
- 📱 Responsive design for mobile devices

## Technologies

- HTML5
- CSS3
- JavaScript
- OMDb API
- LocalStorage
